# LB Visualizer

**Music Visualizer & Lyrics Studio** — by Legendary Beats.

This repository distributes the released application. The source code is not
published here.

## Download

Get the latest version from the [**Releases**](https://github.com/cjddr6qffj-ctrl/lb-visualizer/releases/latest) page:

1. Download `LB-Visualizer-<version>-arm64.dmg`
2. Open it and drag **LB Visualizer** to your Applications folder

Requires a Mac with Apple Silicon (M1 or newer), macOS 12 or later.

> The app is not signed with an Apple Developer ID yet, so on first launch macOS
> will refuse to open it. Right-click the app → **Open**, or allow it under
> System Settings → Privacy & Security → **Open Anyway**.

## Updates

LB Visualizer checks this repository for new releases on startup and offers the
update when one exists. It works fully offline; without a connection it simply
carries on.
